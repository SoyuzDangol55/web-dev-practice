# Weather App

A simple and clean weather web application that shows current weather information for any city.

## Features
- Search weather by city name
- Displays temperature, humidity, wind speed
- Dynamic weather icon
- Responsive design
- Default weather shown for Kathmandu

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- OpenWeatherMap API

## How to Use

1. Clone the repository
2. Open `index.html` in your browser
